# Coop's WoW Launcher

The v1.2.0 launcher downloads missing required HD patch archives for the qualified Coop's HD enUS 3.3.5a client. Exact SHA-256 validation, transactional installation, rollback and crash recovery remain enforced. Existing incompatible baseline files remain blocked.

See [DISTRIBUTION.md](DISTRIBUTION.md) for verified payload preparation, tests, self-contained Windows packaging and the coordinated release procedure. See [RELEASE-NOTES.md](RELEASE-NOTES.md) for player-facing changes.

[Download the Windows launcher](https://github.com/coopscollectionbiz-debug/coops-wow-launcher/releases/download/v1.2.0/Coops-WoW-Launcher-v1.2.0-win-x64.zip), extract it, choose your supported HD client folder, then click **Check / Install Patch**. Required patch downloads are hosted with the [v1.2.0 release](https://github.com/coopscollectionbiz-debug/coops-wow-launcher/releases/tag/v1.2.0).
